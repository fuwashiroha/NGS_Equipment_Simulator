从 swiki 导入特殊能力

  1. 在浏览器中打开 swiki，进入「特殊能力 → 一覧比較表」。
  2. 等待表格加载完成，按 Ctrl＋S（Mac：⌘＋S），保存类型选择「网页，仅 HTML」或「网页，全部」。
  3. 点击下方按钮，选择保存的 .html 或 .htm 文件；无需选择附带的资源文件夹。不要使用 PDF 或 MHTML。
  4. 新增能力以日文名称保存在「自定义能力」。重复项自动跳过；已有能力和配装不变。
