# NGS 配装模拟器

[日本語](README.md) | 简体中文

用于配置 PSO2 NGS 装备、比较单次命中期望伤害的离线工具。

## 主要功能

- 编辑武器、三件防具、戒指、项链及特殊能力；悬停戒指选项查看效果。
- 设置主副职业等级、目标与攻击条件、料理及玛古。
- 一键配置特殊能力、优化武器普通槽、添加自定义能力。
- 伤害比较、方案保存与 JSON 导入导出。
- 紧凑排版、中日文切换、跟随系统／浅色／深色配色。

## 使用方法

下载 `index.html`，用浏览器直接打开，无需安装。

选择职业和攻击条件，调整装备即可查看结果。配置保存在浏览器中，跨设备转移时请先「导出」。

本工具计算单次命中伤害，不自动计算完整攻击循环的 DPS 或独立追击。
