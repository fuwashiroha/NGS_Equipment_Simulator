用于配置 PSO2 NGS 装备、比较单次命中期望伤害的离线网页工具。

## 主要功能

- 武器与三件防具的能力同屏编辑，支持添加、保存和删除自定义能力。
- 显示武器上升、伤害补正及不同名能力数，联动计算种类丰盛增伤。
- 自定义职业、等级、敌防、增益、T1戒指与攻击方式。
- 比较非倒地常态／潜在触发伤害，支持基准武器百分比显示。
- 一键优化武器的3个普通能力槽，使非倒地常态期望最大。
- 配装保存、JSON备份导入导出、中日文切换。

## 使用方法

下载 HTML 文件，用浏览器打开即可，无需安装。

配置保存在浏览器中，移动或更新文件前请导出备份。

※ 本工具计算单次命中伤害，不自动计入完整循环DPS及独立追击。
